## ADDED Requirements

### Requirement: 文件发送
系统 SHALL 支持从本地文件读取内容并通过串口发送。

#### Scenario: 选择并发送文件
- **WHEN** 用户勾选 "传输文件" 或 "打开文件"，通过文件对话框选择一个文件
- **THEN** 系统分块（每块 256 字节）读取文件并通过串口发送

#### Scenario: 大文件警告
- **WHEN** 用户选择大于 1MB 的文件
- **THEN** 系统弹出警告提示文件较大，询问是否继续发送

#### Scenario: 串口未打开时发送文件
- **WHEN** 用户选择文件但串口未打开
- **THEN** 系统提示 "请先打开串口"，不发送数据

### Requirement: 接收日志存文件
系统 SHALL 支持将接收数据实时写入本地文件。

#### Scenario: 开始记录日志
- **WHEN** 用户勾选 "保存文件" 并通过文件对话框选择保存路径
- **THEN** 系统创建文件并将所有后续接收数据实时追加写入

#### Scenario: 停止记录日志
- **WHEN** 日志记录进行中，用户取消勾选 "保存文件"
- **THEN** 系统关闭文件并停止写入

#### Scenario: 关闭串口时自动停止日志
- **WHEN** 日志记录进行中，用户关闭串口
- **THEN** 系统自动关闭日志文件
