## ADDED Requirements

### Requirement: 定时发送
系统 SHALL 支持按用户设定的时间间隔自动重复发送数据。

#### Scenario: 启动定时发送
- **WHEN** 用户勾选 "定时发送" 复选框，在间隔输入框填入 `500`（ms），串口已打开
- **THEN** 系统每隔 500ms 自动将发送区内容发送一次

#### Scenario: 停止定时发送
- **WHEN** 定时发送正在进行中，用户取消勾选 "定时发送"
- **THEN** 系统立即停止自动发送

#### Scenario: 串口关闭时自动停止
- **WHEN** 定时发送正在进行中，用户关闭串口
- **THEN** 系统自动停止定时发送

#### Scenario: 发送间隔下限保护
- **WHEN** 用户设置间隔为 `5`（ms，低于 10ms 下限）
- **THEN** 系统自动将间隔调整为 10ms

#### Scenario: 定时发送与 HEX 模式配合
- **WHEN** 定时发送启动且 HEX 发送模式已勾选
- **THEN** 系统每次定时触发时先进行 HEX 解析再发送
